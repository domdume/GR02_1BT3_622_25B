# Recomendación para la base de datos H2

- La base de datos se almacena en la carpeta relativa `./data/testdb`.
- Asegúrate de que la carpeta `data` exista en la raíz del proyecto antes de ejecutar la aplicación.
- Esta configuración permite que todos los miembros del equipo trabajen sin modificar rutas locales.
- Si tienes problemas de permisos, verifica que el usuario tenga acceso de escritura a la carpeta `data`.
